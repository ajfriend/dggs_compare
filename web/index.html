Discrete global grid systems — H3, S2, A5, ISEA7H, IVEA7H, ISEA3H, IVEA3H, ISEA4T, rHEALPix, hex9 — compared by per-cell shape and area.

Every cell is measured as a spherical polygon — vertices on the unit sphere, edges great circles. Systems that define their cells on an ellipsoid are mapped to the sphere by the area-preserving authalic latitude, so a system that is exactly equal-area on its own surface stays exactly equal-area here.

Globes — cells colored by the selected metric

One globe per system, every system at a resolution matched to the common cell size set by the Resolution menu (the default is the finest), colored on a shared scale so the systems compare directly. The Metric menu picks what is colored: aspect ratio, or cell area relative to the resolution's exact mean (an equal-area system reads near-constant; a hexagonal system's 12 pentagons pop out well below the mean). Drag to rotate, scroll to zoom, hover for a cell's id and value. The Colormap menu picks the colors; the Scaling menu picks how they are spread along the value range — hold one fixed and switch the other to see how the choice changes what's visible. Globes, legend, and histogram update together.

The bars are the hovered globe's distribution of the selected metric (log count); the white line marks the hovered cell. Its position lines up with the color bar below — both linear in the value — so you can read where a cell sits in the distribution and how the color scale places it. Grey marks the rare cells whose aspect ratio could not be certified.

Aspect ratio (AR) is the major/minor axis ratio of a cell's tightest enclosing-cone ellipse (the per-cell analogue of Tissot's indicatrix): AR = 1 is isotropic, AR > 1 is elongated. Tiling a sphere forces some elongation somewhere — these plots compare how much each system has; the globes show where it puts it.

Area is shown relative to each resolution's exact mean cell area — the sphere's area divided by the cell count, 4π/N — so a perfectly equal-area grid reads 1.0 everywhere, and any spread is areal distortion.

Cell-area distributions

Cell area of each system at its working (~H3 r9-sized) resolution — every cell included. Each stat line pairs the all-cells max/min with the central-99.9% ratio (p99.95/p0.05): one uniform trim, identical for every system, no excluded cell classes.

Shape vs area

Aspect ratio against cell-area ratio at the working resolutions, shown both ways: all-cells extremes on the left, central-99.9% statistics on the right. Down and to the left is better; the star marks the ideal grid.
