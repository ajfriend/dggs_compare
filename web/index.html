Discrete global grid systems — H3, S2, A5, ISEA7H, IVEA7H, ISEA3H, IVEA3H, ISEA4T, rHEALPix, hex9 — compared by per-cell shape and area.

Every cell is measured as a spherical polygon — vertices on the unit sphere, great-circle edges. Systems declared on an ellipsoid are brought to the sphere by the area-preserving authalic latitude, so a system that is exactly equal-area on its declared surface measures exactly equal-area here.

Globes — cells colored by the selected metric

One globe per system at its coarsest full-coverage resolution, colored on a shared scale so the systems compare directly. The Metric menu picks what is colored: aspect ratio, or cell area relative to the resolution's exact mean (equal-area systems read near-constant, with the 12 pentagons popping out well below the mean). Drag to rotate, scroll to zoom, hover for a cell's id and value. The Colormap menu picks the colors; the Scaling menu picks where along the value axis they are spent — hold one fixed and switch the other to see how the choice changes what's visible. Globes and legend update together.

The bars are the hovered globe's distribution of the selected metric (log count); the white line marks the hovered cell. Its position lines up with the color bar below — both linear in the value — so you can read where a cell sits in the distribution and how the color scale places it. Grey = did-not-certify (AR only).

Aspect ratio (AR) is the major/minor axis ratio of a cell's tightest enclosing-cone ellipse (the per-cell analogue of Tissot's indicatrix): AR = 1 is isotropic, AR > 1 is elongated. Tiling a sphere forces some elongation somewhere — these plots compare how much each system has, and where it puts it.
