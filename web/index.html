Discrete global grid systems — H3, S2, A5, ISEA7H, IVEA7H, ISEA3H, IVEA3H, rHEALPix — compared by per-cell shape. Aspect ratio (AR) is the major/minor axis ratio of a cell's tightest enclosing-cone ellipse (the per-cell analogue of Tissot's indicatrix): AR = 1 is isotropic, AR > 1 is squished. Since these grids are ~equal-area, AR is where the unavoidable distortion surfaces.

Globes — cells colored by aspect ratio

One globe per system at its coarsest full-coverage resolution, colored on a shared AR scale so the systems compare directly. Drag to rotate, scroll to zoom, hover for a cell's id and AR. Use the Color scale menu to switch colormap + value transform — the globes and legend update together, so you can see how the choice (e.g. perceptually-uniform linear viridis vs. the stretched default) changes what's visible.
